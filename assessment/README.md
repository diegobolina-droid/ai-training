# Assessment & Evaluation

Guidelines for evaluating student work and measuring progress throughout the training program.

---

## 📊 Assessment Structure

### Daily Labs (60%)
Each day includes a hands-on lab project that is graded:

| Day | Lab | Weight |
|-----|-----|--------|
| Day 1 | URL Shortener with AI | 10% |
| Day 2 | Code Analyzer Agent | 15% |
| Day 3 | Migration Workflow Agent | 15% |
| Day 4 | RAG System + Evaluation | 15% |
| Day 5 | **Capstone Project** | 25% |

### Participation & Engagement (20%)
- Active participation in discussions
- Helping peers
- Asking thoughtful questions
- Completing exercises

### Portfolio Quality (20%)
- Code quality and organization
- Documentation completeness
- Deployment and production readiness
- GitHub repository presentation

---

## 🎯 Grading Criteria

### Technical Implementation (50%)
- **Functionality:** Does it work as specified?
- **Code Quality:** Clean, readable, well-structured code
- **Best Practices:** Following AI engineering patterns
- **Error Handling:** Robust error handling and edge cases

### Understanding & Documentation (30%)
- **Explanation:** Can you explain your approach?
- **Documentation:** Clear README and inline comments
- **Decision Rationale:** Why you made certain choices
- **Trade-offs:** Understanding of alternatives

### Innovation & Polish (20%)
- **Beyond Requirements:** Going above and beyond
- **User Experience:** Thoughtful UX/UI
- **Performance:** Optimization and efficiency
- **Creativity:** Novel approaches or features

---

## 🏆 Capstone Project

The Day 5 capstone is your major portfolio piece.

### **[Capstone Rubric](./capstone-rubric.md)**

Detailed grading criteria for the final project including:
- Project selection and scope
- Implementation quality
- Evaluation and testing
- Production readiness
- Presentation and documentation

### Capstone Options

Choose one of four paths:
1. **AI Code Review Bot** - Automated PR review system
2. **Smart Documentation Generator** - AI-powered docs from code
3. **Intelligent Search Engine** - Semantic code search
4. **Testing Copilot** - Automated test generation

---

## ✅ Completion Requirements

To receive your certificate, you must:

1. **Complete all 5 labs** (passing grade: 70%+)
2. **Deploy your capstone** to production
3. **Present your capstone** (5-minute demo)
4. **Maintain a GitHub repo** with all projects
5. **Achieve 70%+ overall** in the course

## 📈 Progress Tracking

### Self-Assessment

Use the [Checklists](../guides/checklists.md) to track:
- Daily learning objectives completed
- Labs submitted and graded
- Skills mastered
- Portfolio readiness

### Feedback Approach

Recommended feedback structure:
- **Daily:** Quick feedback on lab submissions
- **Mid-week:** Progress check-in (Day 3)
- **Final:** Comprehensive capstone review

---

## 💡 Tips for Success

### Get High Grades:
- Start labs early (don't wait until end of day)
- Ask questions when stuck (don't struggle for hours)
- Review rubrics before starting projects
- Test thoroughly before submitting
- Write clear documentation as you code

### Maximize Learning:
- Complete optional exercises
- Help other students (teaching reinforces learning)
- Experiment beyond requirements
- Read recommended resources
- Join study groups

---

## ⚖️ Academic Integrity

We expect:
- Original work (you write the code)
- Proper attribution (cite sources and helpers)
- Collaboration encouraged (but submit your own)
- AI tools allowed (as learning assistants)

**Using AI tools (Claude, ChatGPT, Copilot) is encouraged!** This training program expects you to use AI effectively. Just understand what the code does.
